# sonmat-maker

손맛 햅틱에 게임을 붙이고 다듬는 제작 도구: 분석 도구(`tools/`), 초기 모델은 앱에 있다(`sonmat/data/model.json`, 자동 셋업·모델에서 프로필 만들기 코드 = `sonmat/tools/gamesetup/autosetup.py`, 여기 `tools/autosetup.py`·`new_profile.py` 는 그것을 부른다).
게임 레포는 `<games>/<id>/` 에 받아 두고 작업한다. Claude 스킬·에이전트는 [sonmat-skills](https://github.com/ErikKim/sonmat-skills).
